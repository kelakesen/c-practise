## fgets

### 函数原型
```c

char *fgets(char *str, int n, FILE *stream);
```
## 功能分步解析

### 读取规则
`fgets` 从 `stream` 中读取字符，直到发生以下任一情况：

1. 已经读取了 `n-1` 个字符；
2. 遇到了换行符 `'\n'`（该换行符会被存储在缓冲区中）；
3. 到达文件末尾（EOF）。

### 存储细节

- 如果读取到换行符，换行符会被写入缓冲区，然后在之后加上 `'\0'` 结束字符串。
- 如果因达到长度限制而停止，缓冲区中不会包含换行符，但会添加 `'\0'`。
- 如果因 EOF 停止，缓冲区包含已读字符和 `'\0'`。

### 与 `gets` 的区别

- `gets` 不检查缓冲区大小，极其危险，已被 C11 标准移除。
- `fgets` 限制读取长度，安全。

## 注意事项与坑点

1. 缓冲区大小：必须确保 `n` 不超过实际缓冲区大小，否则溢出。
2. 保留换行符：`fgets` 会在读取到换行时保留它，处理时通常需要删除。
3. EOF 与错误区分：返回 `NULL` 可能是 EOF 或错误，可用 `feof` 和 `ferror` 判断。
4. 长度不足时：如果一行超过 `n-1` 字符，`fgets` 只读取部分，剩余字符留在输入流，下次继续读。这可能导致逻辑问题，需注意循环处理。
5. 与 `scanf` 混用：`scanf` 可能留下 `'\n'`，导致 `fgets` 立即读取到空行。建议只使用 `fgets` 处理所有输入。
