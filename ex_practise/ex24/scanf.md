## scanf

### 函数原型

```c
int scanf(const char *format, ...);

```
核心行为：

- 从标准输入 stdin 按格式字符串解析数据。

- 大多数格式说明符（%d、%f、%s）自动跳过前导空白。

- 格式字符串中的普通字符必须与输入完全匹配，否则停止。

- 输入是行缓冲的：必须按回车后 scanf 才能读取。

返回值的意义：

- 返回成功赋值的项数。

- 若输入结束（EOF）或发生错误，返回 EOF。

**误区**

1. **不检查返回值**
   - 输入错误或 EOF 时，部分变量未赋值，使用未初始化的值导致未定义行为。
   - 务必：检查返回值是否等于期望的项数。

2. **缓冲区残留**
   - 格式不匹配时，导致失败的字符仍留在输入流，下一次 `scanf` 再次读到，可能死循环。
   - 解决：用 `while ((c = getchar()) != '\n' && c != EOF);` 清空行。

3. **`%c` 不跳过空白**
   - `%c` 会读取下一个字符，包括空格、换行。
   - 如果之前有 `%d`，输入 `123\n` 后，`%c` 会读取到 `\n`。
   - 解决：在 `%c` 前加空格 `scanf(" %c", &ch);` 跳过空白。

4. **字符串溢出**
   - `%s` 不检查长度，输入超长会溢出缓冲区。
   - 解决：使用宽度限制 `%49s`。

5. **格式字符串中多余空格**
   - 通常无害（匹配任意空白），但可能误导，非必要不加。

6. **混合使用 `scanf` 和 `gets`/`fgets`**
   - `scanf` 读取后可能留下 `\n`，导致后续 `fgets` 读到空行。
   - 解决：清空缓冲区或避免混用。

--- ---

推荐做法
- 用 fgets + sscanf 替代：先读取整行，再解析，错误易于恢复，缓冲区可控。

- 始终检查返回值：确保读取成功再使用变量。

- 必要时清空输入缓冲区。

```c
// 安全替代示例
char line[256];
if (fgets(line, sizeof(line), stdin)) {
    int a;
    if (sscanf(line, "%d", &a) == 1) {
        printf("Read: %d\n", a);
    } else {
        printf("Invalid input.\n");
    }
}
